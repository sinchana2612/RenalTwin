# Data provenance

Default demo data are generated by `renaltwin.data.synthetic_cohort` with a fixed seed. All simulator coefficients are assumptions, not clinical estimates. The model evaluation therefore measures consistency with the simulator and is not clinical evidence.

Optional sources: UCI Chronic Kidney Disease dataset (id 336, CC BY 4.0; 400 cross-sectional instances) and MIMIC-IV Clinical Database Demo v2.2 (de-identified demo; ODbL terms apply). These sources are not linked to one another or to synthetic patients. Optional acquisition adapters are not included in the minimal working implementation; do not imply downloaded real data are supported by the default commands.
