# 3-minute demo script
1. Show the disclaimer and data provenance page.
2. Create a synthetic twin and ingest historical eGFR measurements at least 60 days apart.
3. Show the twin status and longitudinal chart.
4. Run prediction and show the model version and synthetic-model disclaimer.
5. Add sensor readings and explain that the clinical-only model score is unchanged.
6. Add a new eGFR reading and show state version/history update.
7. Demonstrate reset and discuss that the model is not clinically validated.
