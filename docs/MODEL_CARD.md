# Model card

**Intended use:** demonstration of a longitudinal digital-twin software pattern. **Not for diagnosis, triage, or treatment.**

**Target:** synthetic label approximating a future 30% eGFR decline. **Training data:** synthetic simulator only. **Primary features:** demographics, comorbidities, repeated eGFR and other synthetic labs. **Model:** logistic-regression baseline with median imputation and standardization.

Metrics are generated by running the pipeline and stored in `artifacts/models/v1/metrics.json`. They must not be interpreted as clinical performance. Known limitations include simulator circularity, lack of real longitudinal outcome data, no independent external validation, and synthetic sensors.
